# JPSForecast 日本株予測プロジェクト：実験計画・モデル学習詳細ドキュメント

## プロジェクト概要
* **目的** : 信用レバレッジ取引を前提とした、個別日本株の「右側テール（特大の急騰）」の確実な捕捉と、「左側テール（致命的な暴落・追証）」の完全回避を両立する超高度複利運用（目標: 数年で2,000万円から10億円への到達）。
* **アプローチ** : 「純粋なアルファ予測」と「絶対的なリスク予測」をそれぞれ独立した専門AIに担わせ、最終的な「運用効用」をメタモデルで統合する**「3層カスケード・スタッキング・アーキテクチャ」**を採用。
* **基本定義** : 複利運用との整合性および外れ値の数学的安定性を担保するため、すべてのリターン計算は**対数リターン（Log Return）**をベースとし、モデル間のスケールを統一する。

## アーキテクチャ設計（3層カスケード・スタッキング）
単一のモデルに相反する学習（急騰を狙うことと、暴落を避けること）をさせることの数理的矛盾を排除するため、役割を完全に分離した4つのベースモデルと、1つのメタモデルでシステムを構築する。

### 【第1層】事前パージ（絶対防衛ライン）
* **STR守り（60日ジリ貧予測）** : 長期的なファンダメンタルズ崩壊・ダウントレンド銘柄をパージする。
* **TAC守り（5日パニック予測）** : 決算後等の突発的な暴落・追証リスクを持つ銘柄をパージする。

### 【第2層】アルファ抽出（攻撃ライン）
* **STR攻め（60日クオリティ）** : 突発的ノイズを無視し、安定して上昇するクオリティの高いトレンド銘柄を抽出する。
* **TAC攻め（5日ホームラン）** : リスクを度外視して、右側テール（+4.5の特大急騰）の火種を持つ銘柄を抽出する。

### 【第3層】メタモデル（資金配分とポートフォリオ構築）
第1層が許可した銘柄の中から、第2層のスコアを組み合わせて、最終的なTop-10銘柄とそのレバレッジ掛け目を決定する。

### TAC攻め
* **Loss** : カスタム非対称MSE (alpha: [2.5, 4.0], beta: 1.0)
* **Step 4 Metric** : Min(NDCG@10 in all Folds) の最大化
* **意図** : 相場環境を問わず「最低限の特大アルファ」を確保する。

### STR攻め
* **Loss** : Fair Loss (fair_c: [8.0, 15.0])
* **Step 4 Metric** : ICIR の最大化
* **意図** : レジームごとのブレを嫌い、滑らかで安定した予測を持続させる。

* **Loss** : Quantile Loss (alpha: [0.05, 0.20])
* **Step 4 Metric** : Min(RankIC in all Folds) の最大化
* **意図** : 「特定のFoldで防衛が機能しない」という穴を許さない鉄壁の盾。

### STR守り
* **Loss** : Tweedie Loss (variance_power: [1.1, 1.9])
* **Step 4 Metric** : Min(RankIC in all Folds) の最大化
* **意図** : ドローダウンの真の分布形状を前提としたリスク算出。


## ターゲット層化サンプリングおよびウエイト設定

### 1. 基本コンセプト（Target-Stratified Sampling）
本手法の最大の目的は、**「予測価値の低い平時のノイズだけを減らし、モデルに学習させたい決定的なイベント（テール）は全て残す」**非対称なデータ構築を行うことです。
ターゲット変数の絶対値、またはボラティリティを基準に抽出率（間引き率）を動的に変化させます。

* **テール部分（重要イベント）：**
  ターゲットが上位・下位20%に該当する日、または前日のHV（ヒストリカルボラティリティ）が急増した日のサンプルは、**ストライド1（100%保持）**とします。
* **センター部分（平時ノイズ）：**
  ターゲットが0付近で値動きが乏しい「退屈な相場」のサンプルは、**ストライド3〜5（ランダムに20%〜30%程度に間引く）**設定とします。
* **導入による効果：**
  重要な短期シグナルを一切逃すことなく、データ量と過学習（平時のノイズへの過剰適合）のリスクだけを効率的に削減できます。

---

### 2. ターゲット別の層化定義（テールとセンターの分類）

#### ① TAC攻め（5日ホームラン予測）
* **テール（ストライド1で完全保持）**
  * **ロジック:** 日次クロスセクションにて、ターゲット値が**上位20%**に入る、または絶対値が +1.5 以上のサンプル。
  * **理由:** 本モデルは「特大の急騰」を当てる狂戦士です。上値見逃しを重罰とするAsymmetric MSEで学習させるため、急騰の初動や直前の微細なシグナルを一つでも落とすと致命傷になります。右側テールは絶対保護領域です。
* **センター（間引き対象）**
  * **ロジック:** ターゲット値が -1.5 〜 +0.5 程度の「退屈な値動き」のサンプル。
  * **理由:** 左側の下落予測は守りモデルに任せる設計であり、微損・微益のサンプルはノイズでしかありません。これらを間引くことで「何もない平時」への過剰適合を防ぎます。

#### ② STR攻め（60日クオリティ予測）
* **テール（ストライド1で完全保持）**
  * **ロジック:** 日次クロスセクションにて、ターゲットの絶対値（正負両方）が**上位・下位あわせて30%**に入るサンプル。
  * **理由:** クオリティの高い中長期トレンドを綺麗に順位付けする（RankIC最大化）役割を持ちます。良いトレンド（右テール）だけでなく、明確なダウントレンド（左テール）も「悪い銘柄」として正しく順位付ける必要があるため、両極端を保持します。
* **センター（間引き対象）**
  * **ロジック:** ターゲット値がゼロ付近（Sharpeがほぼゼロ）のサンプル。
  * **理由:** 60日間方向感のないレンジ相場や流動性の低い銘柄群です。間引くことで、Fair Lossが「明確なトレンドを持つデータ」の学習に強くフォーカスできるようになります。

#### ③ TAC守り（5日パニック予測）
* **テール（ストライド1で完全保持）**
  * **ロジック:** ターゲット値（最大下落率）が -0.05（-5%）より悪い（数値として小さい）サンプル。
  * **理由:** 本モデルは突発的な暴落の防衛線を引く盾です。Quantile Lossで下位の最悪シナリオを学習するため、「暴落の前日」を含む僅かな急落の兆候も1日たりとも漏らしてはいけません。
* **センター（間引き対象）**
  * **ロジック:** ターゲット値が 0.0 〜 -0.02 に収まる、無風または微小な押し目程度のサンプル。
  * **理由:** 5日間で最大2%しか下がらない安全な期間は、守りモデルが学習すべきリスクを含んでいません。間引くことで、学習データ内の真の危険日（左テール）の濃度を高めます。

#### ④ STR守り（60日ジリ貧予測）
* **テール（ストライド1で完全保持）**
  * **ロジック:** ターゲット値（MDD）が 0.15（15%）以上のサンプル、または前週比でMDDが急拡大したサンプル。
  * **理由:** ファンダメンタルズ劣化による構造崩壊リスクをTweedie Lossで学習します。ドローダウン分布の「右に極端に長い尾」を構成するサンプル群であり、これを保持しないとTweedie Variance Powerが正しく機能しません。
* **センター（間引き対象）**
  * **ロジック:** ターゲット値（MDD）が 0.0 〜 0.05 未満の、60日間でほとんど下落しなかったサンプル。
  * **理由:** ゼロ付近に大量集中する無傷のサンプルです。100%保持するとゼロ過剰（Zero-Inflated）になり、モデルが「常にリスクゼロ」と予測する方へ引っ張られるため、積極的に間引きます。

### 3. モデル×ターゲット別の実装方針（サンプリング vs ウエイト）

アーキテクチャおよびターゲットの目的に応じて、物理的な「サンプリング（間引き）」と「ウエイト設定（重み付け）」を厳格に使い分けます。

* **STRモデルの制約:** RankIC最大化を重視するため、データを物理的に間引くとRankICの計算構造（順位付けの母集団）が壊れるリスクがあります。したがって、STRでは層化サンプリングではなく「ウエイト設定」を適用します。
* **線形モデル（ElasticNet）の制約:** データの物理的な間引き（Drop）は厳禁です。全データを保持した上で、「`sample_weight`（サンプル重み）による連続的なペナルティ調整」を行うのが絶対的なセオリーです。

#### 【最終定義】実装マトリクス

##### A. TAC（攻め＆守り）
物理的なデータ間引き（層化サンプリング）を中心に適用します。
* **LGBM:**
  * Tail: 100%保持
  * Others: 100%保持
  * Center: 25%保持
* **DL（ディープラーニング）:**
  * Tail: 100%保持
  * Others: 50%保持
  * Center: 20%保持
* **ElasticNet:** （※物理的間引きはせずウエイトのみ）
  * Tail: Weight = 3.0 〜 5.0
  * Others: Weight = 1.0
  * Center: Weight = 0.1

##### B. STR攻め
全体順位を維持しつつ計算負荷を下げるため、ウエイト設定と均等な日付間引き（Stride=11）を併用します。
* **LGBM:**
  * ウエイト: Tail = 1.5 / Others = 1.0 / Center = 0.5
  * サンプリング: ランダム日付間引き（Interval = 11）
* **DL（ディープラーニング）:**
  * サンプリング: 日付間引き（Interval = 11）のみ実施
* **ElasticNet:**
  * ウエイト: Tail = 1.5 〜 2.0 / Others = 1.0 / Center = 0.5
  * サンプリング: 日付間引き（Interval = 11）

##### C. STR守り
構造崩壊リスク（MDD）を過大評価させるため、Tailに非常に強いウエイトを置きます。
* **LGBM:**
  * ウエイト: Tail = 3.0 / Others = 1.0 / Center = 0.5
  * サンプリング: 日付間引き（Interval = 11）
* **DL（ディープラーニング）:**
  * サンプリング: 日付間引き（Interval = 11）のみ実施
* **ElasticNet:**
  * ウエイト: Tail = 2.0 / Others = 1.0 / Center = 0.3 〜 0.5
  * サンプリング: 日付間引き（Interval = 11）

# Step 3: MDA (Mean Decrease Accuracy) による特徴量選定とターゲット別評価指標

## 1. MDAによる特徴量選定の概要と算出方法

### 概要
ツリー系モデル（LightGBMなど）のビルトイン重要度（Split/Gain）は、特徴量間の相関（マルチコ）やカーディナリティの高さによってノイズを過大評価する傾向がある。MDAは、Validationデータセット上で実際に特定の特徴量配列をシャッフル（破壊）し、予測精度の低下度合いを直接計測することで、その特徴量の「真の限界的寄与度」を数学的に抽出する実運用レベルのノイズパージ手法である。

### 算出方法（Purged K-Fold CVベース）
1. **ベースライン評価:** Step 2で決定したアンカーパラメータ（例: `feature_fraction=0.1`, 強力なL1/L2正則化等）を使用し、全特徴量でモデルを学習。Validationデータに対するベースラインの評価スコアを算出する。
2. **シャッフル推論:** 評価対象の特徴量 $i$ の列データをランダムにシャッフルし、特徴量 $i$ のシグナルのみを破壊した状態で再度推論を行う。
3. **MDA算出:** `MDA = ベースラインスコア - シャッフル後スコア` （※指標により正負の向きは調整）。これをFoldごとに計算する。
4. **Feature Sharpeの計算:** 各特徴量の全Foldにおける `MDAの平均値 (Mean)` を `MDAの標準偏差 (Std)` で割り、`Feature Sharpe` を算出する。
5. **パージ（選定）:** `Feature Sharpe > 0` （シャッフルによって確実に精度が低下した＝予測に不可欠である）を満たす特徴量のみを「真のアルファ源泉」として残し、ゼロまたはマイナスとなったノイズ特徴量を完全に破棄する。

## 2. ターゲット別評価指標（MDA算出用エンジン指標）

モデルが「何を学習し、何を守るべきか」を決定づけるため、ターゲットの性質（右側テール／左側テール／ホライズン）に完全に特化した評価指標をMDA算出に用いる。

### ① TAC攻め（短期5日・右側テールの特大急騰捕捉）
* **推奨指標:** `NDCG@10` (Normalized Discounted Cumulative Gain)
* **指標の定義:** 上位10銘柄のランキング品質を評価する指標。上位の順位付けが正確であるほど対数的に高いスコアを与える。
* **推奨理由:** TAC攻めの至上命題は「トップ数銘柄が確実に特大急騰すること」であり、中〜下位の順位付けは一切不要である。NDCG@10をMDAに用いることで、右側テールの発火条件（例: 決算サプライズ×流動性急増など）に寄与しない凡庸な特徴量を容赦なくパージし、極めて純度の高いSniper（狙撃）モデルを構築できる。

### ② TAC守り（短期5日・左側テールのパニック暴落回避）
* **推奨指標:** `AP_Severe` (Severe Drop向け Average Precision / PR-AUC)
* **指標の定義:** ターゲットが「-5%」「-7%」「-10%」等の複数の厳しい暴落閾値を下回るイベントを陽性とし、適合率（Precision）と再現率（Recall）のカーブの下側面積（AUC）を算出・平均する指標。
* **推奨理由:** `Recall_Gate` のような非連続な指標は、スコアの崖による分散爆発を起こすためMDAには不適である。金融の暴落イベントは極端な不均衡データであり、PR-AUCを採用することで「偽陽性（無駄なアラート）」を厳しく罰しつつ、致命的な暴落を捉える連続的で堅牢なノイズ検知が可能となる。

### ③ STR攻め（中期60日・ファンダメンタルズとトレンドの順張り）
* **推奨指標:** `Everyday_RankIC` (毎日のスピアマン順位相関係数)
* **指標の定義:** 全サンプル期間における「毎日」の予測スコアと実リターンの順位相関（RankIC）を算出し、その平均をとる指標。
* **推奨理由:** STR攻めはポートフォリオ（バスケット）全体の安定した順位形成を目的とする。運用評価（バックテスト）ではリバランス日のみを見るのが適切だが、MDAにおける「シグナルの頑健性」を測るフェーズでは、リバランス日に限定する（間引く）と分散が爆発し、優秀な特徴量を誤ってパージするType II Errorを引き起こす。全日程を評価することで最大サンプルサイズを確保し、本物のファンダメンタルズ・ファクターを抽出する。

### ④ STR守り（中期60日・構造的ダウントレンドの排除）
* **推奨指標:** `AP_Severe_STR` (中期ホライズン向け PR-AUC)
* **指標の定義:** STRのホライズン（60日）において、ターゲットが「-15%」「-20%」「-30%」といった構造的なジリ貧・ダウントレンドに陥る銘柄を陽性とし、AP_Severeと同様にPR-AUCを算出する。
* **推奨理由:** 当初検討したC-index（Concordance Index）は、右側や中央の不要なペア（例: +20%と+15%の勝敗）まで評価に含んでしまうため、守りに特化した特徴量がノイズ評価されやすい。STR守りも本質的には「左側テールの検知」であるため、ターゲット閾値を中期向けに深く設定したPR-AUCを使用することで、ダウントレンド回避に直結するシグナルのみを正確に抽出できる。

# Step 4 最終HPO（ハイパーパラメータ最適化）


金融MLにおける最大の罠である「特定レジームへの過学習」を回避するため、最適化指標には単純な平均値（Mean）ではなく「最悪レジームへの耐性（Worst-Fold）」や「リスク調整後リターン（ICIR）」を採用する。また、オプティマイザの計算バジェットを最大化するため、学習率（`learning_rate`）は固定しEarly Stoppingを利用することを基本戦略とする。

---

## 1. ターゲット別 Optuna目的関数（Objective）の定義と選定根拠

各モデルの役割（アルファ抽出 vs リスク回避、短期 vs 中長期）に合わせ、目的関数を厳密に分離する。すべての目的関数は**「最大化（Maximize）」**を最適化の方向とする。

### ① TAC攻め（短期5日・特大急騰予測）
* **ターゲット変数**: `target_tac_vol_scaled_asym_return`
* **Optuna目的関数**: `Worst-Fold NDCG@10` の最大化
  * **定義**: K-Fold CVの全Foldの中で、最もスコアが低かったFoldの `NDCG@10` を最大化する（※解像度を上げるためスコアを100倍して返すことを推奨）。
  * **選定根拠**: 本モデルは「特大急騰銘柄をトップ10にねじ込む」スナイパーモデルである。平均スコアを最大化すると、暴落相場などでトップ10が全て致命的な赤字になるような脆いモデルが選ばれやすい。Worst-Foldを底上げすることで、いかなる悪環境でも最低限のアルファを抽出できる頑健なモデルを構築する。

### ② TAC守り（短期5日・パニック暴落予測）
* **ターゲット変数**: `target_tac_max_neg_path`
* **Optuna目的関数**: `Worst-Fold AP_severe` の最大化
  * **定義**: 全Foldの中で、最も低かったPR-AUC（重度暴落イベントに対する適合率・再現率カーブ面積）を最大化する。
  * **選定根拠**: 守りモデルの至上命題は左側テール（暴落）の確実な検知であり、安全な銘柄を含めた全体の順位付け（RankIC等）を評価するのは数理的な矛盾である。偽陽性を抑えつつ致命的な暴落を見逃さないためのPR-AUCについて、最悪のレジームでの防衛力を最大化し「鉄壁の盾」を構築する。

### ③ STR攻め（中期60日・クオリティトレンド予測）
* **ターゲット変数**: `target_str_sharpe_adj`
* **Optuna目的関数**: `ICIR` (Information Coefficient Information Ratio) の最大化
  * **定義**: 全サンプルの日次RankICの平均値を、日次RankICの標準偏差で割った値。
  * **選定根拠**: 中長期のポートフォリオ運用において最も重要なのは、一発の大きなリターンではなく「アルファの安定性（日々の順位付けのブレの少なさ）」である。ICIRを目的関数にすることで、RankICの絶対値が高く、かつFold間や日々のボラティリティが低い、極めて滑らかな「重戦車」のような予測器を探し出す。

### ④ STR守り（中期60日・構造的ジリ貧予測）
* **ターゲット変数**: `target_str_mdd`
* **Optuna目的関数**: `Worst-Fold AP_severe_STR` の最大化
  * **定義**: 全Foldの中で、最も低かった中長期向けPR-AUC（構造的ジリ貧・ダウントレンドに対するカーブ面積）を最大化する。
  * **選定根拠**: TAC守り同様、学習すべきはTweedie分布の裾野（致命的なドローダウン）のみである。ファンダメンタルズ劣化に伴う長期的な下落リスクの検知力を、最悪のレジーム環境下において最大化する。

## 2. LGBMモデルのHPO探索対象パラメータと探索範囲

Optunaの探索資源（バジェット）を有効活用するため、以下の原則に従う。
* **固定パラメータ（探索除外）**: `learning_rate`（0.005等に固定）、およびターゲット特性に合わせて設定したツリー構造のアンカー（`max_depth`, `num_leaves`, `min_child_samples`）。
* **探索対象パラメータ**: 各分岐で使用する特徴量の割合（`feature_fraction`）、正則化（`lambda_l1`, `lambda_l2`）、およびターゲットの振る舞いを決定づけるカスタムLoss関数のパラメータ。

※Step 3のMDAによって特徴量が少数（30〜45個程度）に厳選されていることを考慮し、`feature_fraction` の探索範囲は意図的に低め（0.1〜0.8程度）にスライド設定している。

### ① TAC攻め（target_tac_vol_scaled_asym_return）
| パラメータ名 | 探索範囲 (Optuna Suggest) | 意図・根拠 |
| :--- | :--- | :--- |
| `feature_fraction` | `[0.1, 0.6]` (Uniform) | 厳選された特徴量から、ごく少数（数個〜20個程度）の強力なファクターの組み合わせで鋭い分岐（Sniper挙動）を作らせる。 |
| `bagging_fraction` | `[0.6, 0.9]` (Uniform) | ランダムなデータのドロップによる過学習防止。 |
| `lambda_l1` | `[0.01, 10.0]` (LogUniform) | ノイズを物理的にゼロに落とすL1正則化。スパース性を高めて狙撃精度を上げる。 |
| `lambda_l2` | `[0.01, 10.0]` (LogUniform) | 重みの爆発を防ぐ。 |
| `asym_alpha` | `[2.5, 4.0]` (Uniform) | **【Loss関数】** 上値見逃しに対するペナルティ倍率。モデルの攻撃力を直接決める最重要パラメータ。 |

### ② TAC守り（target_tac_max_neg_path）
| パラメータ名 | 探索範囲 (Optuna Suggest) | 意図・根拠 |
| :--- | :--- | :--- |
| `feature_fraction` | `[0.2, 0.7]` (Uniform) | 暴落シグナルの組み合わせをある程度広く見せつつ、無駄なノイズを弾く。 |
| `bagging_fraction` | `[0.5, 0.9]` (Uniform) | 暴落イベントの発生時期の偏りを防ぐため、バギングを強め（広め）にかける。 |
| `lambda_l1` | `[0.1, 15.0]` (LogUniform) | 偽陽性（過剰防衛）を防ぐため、TAC攻めよりもL1正則化を強めに設定。 |
| `lambda_l2` | `[0.1, 10.0]` (LogUniform) | 予測値の安定化。 |
| `alpha` | `[0.05, 0.20]` (Uniform) | **【Loss関数】** Quantile Lossの分位数。どれだけ深い暴落（5%〜20%タイル）をターゲットにするかデータから逆算する。 |

### ③ STR攻め（target_str_sharpe_adj）
| パラメータ名 | 探索範囲 (Optuna Suggest) | 意図・根拠 |
| :--- | :--- | :--- |
| `feature_fraction` | `[0.3, 0.8]` (Uniform) | ファンダメンタルズはマクロな全体像を見ることが重要なため、探索範囲の上限を高めに設定する。 |
| `bagging_fraction` | `[0.7, 1.0]` (Uniform) | 中長期モデルはサンプルを間引く恩恵が少ないため、高めに設定。 |
| `lambda_l1` | `[1.0, 20.0]` (LogUniform) | 日次の微小なノイズを完全に無視するため、極めて強力なL1ペナルティを課す。 |
| `lambda_l2` | `[1.0, 20.0]` (LogUniform) | 特徴量間のマルチコを強烈に抑え込み、日々のブレが少ない安定したRankを生成する。 |
| `fair_c` | `[5.0, 15.0]` (Uniform) | **【Loss関数】** Fair Lossにおいて、外れ値（極端なリターン）をMSEからMAEへ切り替える閾値。ノイズ平滑化レベルを最適化。 |

### ④ STR守り（target_str_mdd）
| パラメータ名 | 探索範囲 (Optuna Suggest) | 意図・根拠 |
| :--- | :--- | :--- |
| `feature_fraction` | `[0.3, 0.8]` (Uniform) | STR攻め同様、広い視野でファンダメンタルズや需給の崩壊を複合的に捉えさせる。 |
| `lambda_l1` | `[0.5, 15.0]` (LogUniform) | 構造的要因以外のノイズ（一時的な押し目など）をL1で弾く。 |
| `lambda_l2` | `[0.1, 10.0]` (LogUniform) | リーフの重みを平滑化し、安定したリスクスコアを出力させる。 |
| `variance_power` | `[1.1, 1.9]` (Uniform) | **【Loss関数】** Tweedie Lossの分布形状パラメータ。真のMDD分布（ポアソン寄りかガンマ寄りか）をOptunaに発見させる最重要項目。 |

### 3. コスト関数パラメータの同時最適化について
本プロジェクトでは、コスト関数の形状パラメータ（`asym_alpha`等）を最終HPO（Step 4）の探索対象に含める。これは以下の理由に基づく金融MLのベストプラクティスである。
* **S/N比の改善**: ノイズパージ（Step 3）後のクリーンなデータ環境でこそ、真に最適なペナルティ形状が決定できるため。
* **正則化との相互作用**: L1/L2正則化とLossパラメータのトレードオフを同時に多変量探索（TPESampler）で解決し、バイアスとバリアンスの最適な均衡点に到達するため。
