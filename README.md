# JPSForecast 日本株予測プロジェクト：実験計画・モデル学習詳細ドキュメント

## プロジェクト概要
* **目的** : 信用レバレッジ取引を前提とした、個別日本株の「右側テール（特大の急騰）」の確実な捕捉と、「左側テール（致命的な暴落・追証）」の完全回避を両立する超高度複利運用（目標: 数年で2,000万円から10億円への到達）。
* **アプローチ** : 「純粋なアルファ予測」と「絶対的なリスク予測」をそれぞれ独立した専門AIに担わせ、最終的な「運用効用」をメタモデルで統合する**「3層カスケード・スタッキング・アーキテクチャ」**を採用。
* **基本定義** : 複利運用との整合性および外れ値の数学的安定性を担保するため、すべてのリターン計算は**対数リターン（Log Return）**をベースとし、モデル間のスケールを統一する。

## アーキテクチャ設計
### ターゲット
４種類のターゲットを使用する。機械学習アルゴリズムが「予測不可能なノイズ（外れ値）」によって破壊されるのを防ぐため、各モデルのターゲットに対して物理的なクリップ処理を必ず実行し、目的に応じた損失関数を適用する。

| モデル名 | ターゲット名 | ターゲットの定義 | 前処理(Clip) | 損失関数 (Loss Function) | 意図・理由 |
| :--- | :--- | :--- | :--- | :--- | :--- |
| **TAC alpha** | target_tac_vol_scaled_asym_return | 5日間の非対称・ボラティリティ正規化リターン | [-1.5, +4.5] | カスタム非対称MSE (alpha: 2.5-4.0) | 右側の「特大ホームラン」を狩るための非対称空間を構築。 |
| **STR alpha** | target_str_sharpe_adj | 60日間のSharpe調整済みリターン | [-20.0, +20.0] | Fair Loss (c: 8.0-15.0) | レジームごとのブレを嫌い、滑らかで安定した予測を持続させる。 |
| **TAC risk** | target_tac_max_neg_path | 5日間の最大下落率 | [-0.50, 0.0] | Quantile Loss (alpha: 0.05-0.20) | 「特定のFoldで防衛が機能しない」という穴を許さない鉄壁の盾。 |
| **STR risk** | target_str_mdd | 60日間の最大ドローダウン | [0.0, +0.60] | Tweedie Loss (p: 1.1-1.9) | ドローダウンの真の分布形状を前提としたリスク算出。 |
| **メタ** | target_meta_survival_return | 翌日始値ベース5日対数リターン(HVペナルティ付) | (条件依存) | 効用関数最大化 | 「生存」と「複利最大化」を表現した最終効用関数。 |

各ターゲットを学習させる際に使用するEarlyStopping監視指標には、以下のものを使用する。
tac_alpha : ndcg_10
tac_risk : AP_severe
str_alpha : rank_ic_reb 
str_risk : pr_auc_30pt

* AP_severe
-5%, -7%, -10%の３つの閾値でターゲットを２値変換し、それぞれAverage Precisionを算出、３つのAverage Precisionの平均値を取る

* rank_ic_reb
11日ごとにサンプルを日付目引きをした上でrank ICを算出

* pr_auc_30pt
-30%でターゲットを２値変換し、PR_AUCを算出

### モデル
4種類のアルゴリズム（LightGBM, TCN, FT-Transformer, ElasticNet）を、4種類のターゲット（TAC alpha/risk, STR alpha/risk）それぞれで学習させ、計16個のベース学習器を構築する。
これらの予測値を入力として、**Context Aware Stacking**を適用したメタモデルを構築する。
単一のモデルに相反する学習（急騰を狙うことと、暴落を避けること）をさせることの数理的矛盾を排除するため、役割を完全に分離した4つのベースモデルと、1つのメタモデルでシステムを構築する。
* **【第1層】事前パージ（絶対防衛ライン）**
    * **STR risk（60日ジリ貧予測）** : 長期的なファンダメンタルズ崩壊・ダウントレンド銘柄をパージする。
    * **TAC risk（5日パニック予測）** : 決算後等の突発的な暴落・追証リスクを持つ銘柄をパージする。
* **【第2層】アルファ抽出（攻撃ライン）**
    * **STR alpha（60日クオリティ）** : 突発微細なノイズを無視し、安定して上昇するクオリティの高いトレンド銘柄を抽出する。
    * **TAC alpha（5日ホームラン）** : リスクを度外視して、右側テール（+4.5の特大急騰）の火種を持つ銘柄を抽出する。
* **【第3層】メタモデル（資金配分とポートフォリオ構築）**
    * 第1層が許可した銘柄の中から、第2層のスコアを組み合わせて、最終的なTop-10銘柄とそのレバレッジ掛け目を決定する。


## モデル学習方法
### 1. 基本コンセプト（Target-Stratified Sampling）
本手法の最大の目的は、**「予測価値の低い平時のノイズだけを減らし、モデルに学習させたい決定的なイベント（テール）は全て残す」**非対称なデータ構築を行うことにある。
ターゲット変数の絶対値、またはボラティリティを基準に抽出率（間引き率）を動的に変化させる。
* **テール部分（重要イベント）：**
  ターゲットが上位・下位20%に該当する日、または前日のHV（ヒストリカルボラティリティ）が急増した日のサンプルは、**ストライド1（100%保持）**とする。
* **センター部分（平時ノイズ）：**
  ターゲットが0付近で値動きが乏しい「退屈な相場」のサンプルは、**ストライド3〜5（ランダムに20%〜30%程度に間引く）**設定とする。
* **導入による効果：**
  重要な短期シグナルを一切逃すことなく、データ量と過学習（平時のノイズへの過剰適合）のリスクだけを効率的に削減可能。

### 2. ターゲット別の層化定義（テールとセンターの分類）
#### ① TAC alpha（5日ホームラン予測）
* **テール（ストライド1で完全保持）**
  * **ロジック:** 日次クロスセクションにて、ターゲット値が**上位20%**に入る、または絶対値が +1.5 以上のサンプル。
  * **理由:** 本モデルは「特大の急騰」を当てる狂戦士。上値見逃しを重罰とするAsymmetric MSEで学習させるため、急騰の初動や直前の微細なシグナルを一つでも落とすと致命傷になる。右側テールは絶対保護領域。
* **センター（間引き対象）**
  * **ロジック:** ターゲット値が -1.5 〜 +0.5 程度の「退屈な値動き」のサンプル。
  * **理由:** 左側の下落予測はriskモデルに任せる設計であり、微損・微益のサンプルはノイズに過ぎない。これらを間引くことで「何もない平時」への過剰適合を防ぐ。

#### ② STR alpha（60日クオリティ予測）
* **テール（ストライド1で完全保持）**
  * **ロジック:** 日次クロスセクションにて、ターゲットの絶対値（正負両方）が**上位・下位あわせて30%**に入るサンプル。
  * **理由:** クオリティの高い中長期トレンドを綺麗に順位付けする（RankIC最大化）役割を持つ。良いトレンド（右テール）だけでなく、明確なダウントレンド（左テール）も「悪い銘柄」として正しく順位付ける必要があるため、両極端を保持する。
* **センター（間引き対象）**
  * **ロジック:** ターゲット値がゼロ付近（Sharpeがほぼゼロ）のサンプル。
  * **理由:** 60日間方向感のないレンジ相場や流動性の低い銘柄群。間引くことで、Fair Lossが「明確なトレンドを持つデータ」の学習に強くフォーカス可能となる。

#### ③ TAC risk（5日パニック予測）
* **テール（ストライド1で完全保持）**
  * **ロジック:** ターゲット値（最大下落率）が -0.05（-5%）より悪い（数値として小さい）サンプル。
  * **理由:** 本モデルは突発的な暴落の防衛線を引く盾。Quantile Lossで下位の最悪シナリオを学習するため、「暴落の前日」を含む僅かな急落の兆候も1日たりとも漏らしてはならない。
* **センター（間引き対象）**
  * **ロジック:** ターゲット値が 0.0 〜 -0.02 に収まる、無風または微小な押し目程度のサンプル。
  * **理由:** 5日間で最大2%しか下がらない安全な期間は、riskモデルが学習すべきリスクを含んでいない。間引くことで、学習データ内の真の危険日（左テール）の濃度を高める。

#### ④ STR risk（60日ジリ貧予測）
* **テール（ストライド1で完全保持）**
  * **ロジック:** ターゲット値（MDD）が 0.15（15%）以上のサンプル、または前週比でMDDが急拡大したサンプル。
  * **理由:** ファンダメンタルズ劣化による構造崩壊リスクをTweedie Lossで学習する。ドローダウン分布の「右に極端に長い尾」を構成するサンプル群であり、これを保持しないとTweedie Variance Powerが正しく機能しない。
* **センター（間引き対象）**
  * **ロジック:** ターゲット値（MDD）が 0.0 〜 0.05 未満の、60日間でほとんど下落しなかったサンプル。
  * **理由:** ゼロ付近に大量集中する無傷のサンプル。100%保持するとゼロ過剰（Zero-Inflated）になり、モデルが「常にリスクゼロ」と予測する方へ引っ張られるため、積極的に間引く。

### 3. モデル×ターゲット別の実装方針（サンプリング vs ウエイト）
アーキテクチャおよびターゲットの目的に応じて、物理的な「サンプリング（間引き）」と「ウエイト設定（重み付け）」を厳格に使い分ける。

* **STRモデルの制約:** RankIC最大化を重視するため、データを物理的に間引くとRankICの計算構造（順位付けの母集団）が壊れるリスクがある。したがって、STRでは層化サンプリングではなく「ウエイト設定」を適用する。
* **線形モデル（ElasticNet）の制約:** データの物理的な間引き（Drop）は厳禁。全データを保持した上で、「`sample_weight`（サンプル重み）による連続的なペナルティ調整」を行うのが絶対的なセオリー。

物理的なデータ間引き（層化サンプリング）とサンプル重み（Weight）を厳格に使い分ける。

| カテゴリ | モデル | サンプリング戦略 (Tail / Others / Center) | ウエイト設定 (Tail / Others / Center) | 備考 |
| :--- | :--- | :--- | :--- | :--- |
| **TAC (alpha/risk)** | LGBM | 100% / 100% / 25% | 1.0 / 1.0 / 1.0 | 短期テール捕捉のため物理間引きを優先 |
| | DL | 100% / 50% / 20% | 1.0 / 1.0 / 1.0 | 計算負荷軽減とノイズ排除を両立 |
| | ElasticNet | 100% / 100% / 100% (間引きなし) | 3.0~5.0 / 1.0 / 0.1 | 線形モデルの安定性のため重みで調整 |
| **STR alpha** | LGBM | 日付間引き (Interval=11) | 1.5 / 1.0 / 0.5 | 順位維持のため日付単位で間引く |
| | DL | 日付間引き (Interval=11) | 1.0 / 1.0 / 1.0 | 構造学習を優先 |
| | ElasticNet | 日付間引き (Interval=11) | 1.5~2.0 / 1.0 / 0.5 | トレンドの強弱を重みで表現 |
| **STR risk** | LGBM | 日付間引き (Interval=11) | 3.0 / 1.0 / 0.5 | MDD過大評価のためTail重みを最大化 |
| | DL | 日付間引き (Interval=11) | 1.0 / 1.0 / 1.0 | 汎用的なリスク構造を抽出 |
| | ElasticNet | 日付間引き (Interval=11) | 2.0 / 1.0 / 0.3~0.5 | ゼロ過剰分布への適合を抑制 |

カテゴリ別のTail/Centerの定義は以下の通り。
TAC alpha:
Tail：日次のクロスセクションにおいて、ターゲット値が上位20%に入るサンプル、または絶対値が +1.5 以上のサンプル
Center：ターゲット値が -1.5 〜 +0.5 の「退屈な値動き」のサンプル
STR alpha:        
Tail：日次のクロスセクションにおいて、ターゲットの絶対値（正負両方）が上位・下位あわせて30%に入るサンプル
Center：ターゲット値の絶対値が0.5未満（Sharpeがほぼゼロ）のサンプル
TAC risk:        
Tail：ターゲット値（最大下落率）が -0.05（-5%）より悪い（数値として小さい）サンプル
Center：ターゲット値が 0.0 〜 -0.02 に収まる、無風または微小な押し目程度のサンプル
STR risk:        
Tail：ターゲット値（MDD）が 0.15（15%）以上のサンプル、または前週比でMDDが急拡大したサンプル
Center：ターゲット値（MDD）が 0.0 〜 0.05 未満の、60日間でほとんど下落しなかったサンプル


## 個別モデル実装方針（LightGBM＆DL系）
### 概要
以下の４ステップに沿って実装を行う。
1. **Step1：特徴量スクリーニング**
   準備した全特徴量（約720種類）の中から、明らかに不要なものを除去する。全特徴量を浅い木のLGBMに投入し、SHAP値を使用して重要度を算出。purged kfoldにより複数期間のSHAP値と Feature Sharpe を算出し、Sharpe値が低いものを除去する。
   スクリーニングされた特徴量について、以下の方針に基づきモデル×ターゲット別に暫定特徴量を決定する。
   * **LGBM**: スクリーニングされた特徴量を全投入
   * **TCN**: 未加工特徴量(_RAW)を、時系列加工特徴量(_TSR,_TSZ)に変更して投入
   * **FTT**: 未加工特徴量(_RAW)を、クロスセクショナル加工特徴量(_CSZ,_CSR,_SNZ)に変更して投入
2. **Step2：ラフチューニング**
   各モデルのアンカーパラメータをGridSearchにより決定する。
3. **Step3：特徴量選定**
   決定したアンカーパラメータの元モデル学習を実施し、暫定特徴量のMDA値を算出。purged_kfoldにより複数期間のMDA、sharpe値を算出し、Sharpe値が低いものを除去し、特徴量を確定する。
4. **Step4：最終HPO**
   アンカーパラメータ、確定特徴量を使用して、未チューニングパラメータの最終調整を実施。モデルを確定させる。

### Step2 ラフチューニング
* **「究極のプラトー（岩盤）」の特定:** 単なるTrain/Validスコアの最大化ではなく、未知の相場環境（レジームシフト）においても予測性能が崩壊しない「PBO（バックテスト過学習確率）が低く、かつワーストケースの防衛力が高い」パラメータの安全地帯（プラトー）を見つけ出す。
* **「情報ボトルネック」の最適化:** 金融市場はノイズ（N）がシグナル（S）を圧倒する極端な低S/N環境である。モデルがノイズを暗記できないよう、ターゲットの予測ホライズン（5日先 or 60日先）の難易度に合わせて、表現力の限界（木の深さ、チャネル数、バッチサイズ等）を意図的に絞り込む（意図的アンダーフィットの設計）。
* **コスト関数と監視指標の完全分離:** すべての学習において、勾配を流す「コスト関数（Loss）」と、学習のピークを判定する「監視指標（RankIC, NDCG等）」を完全に分離し、クロスセクショナル（日別断面）評価による遅延Early Stopping（長いPatience）を前提とした骨格を探索する。
* **Step3/Step4に向けた「アンカー（碇）」の確立:** ここで定めた骨格を固定することで、Step3（MDAによる特徴量パージ）における重要度算出のバリアンスを抑え、Step4（ディープアンサンブル）でのバリアンス圧殺効果を最大化する。

モデル×ターゲット別アンカーパラメータと探索範囲は以下の通り。

##### A. LightGBM (LGBM)
決定木アンサンブルは「空間の分割」を行う。ターゲットのノイズレベルに合わせて「木の深さ（表現力）」と「葉ごとの最小サンプル数（ボトムアップ制約）」を探索する。

###### ① ターゲット: TAC alpha (`tac_vol_scaled_asym_return`)
* **特性:** 短期（5日先）の右側テール予測。適度な表現力でモメンタムやボラティリティの微細な変化を捉える必要がある。
* **探索範囲:**
    * `num_leaves`: [3, 7, 15]
    * `max_depth`: [2, 3, 4]
    * `min_child_samples`: [50, 100, 200]
* **理由・妥当性:** 深すぎる木（31以上）は完全に除外。表現力を適度に保ちつつ、Top10銘柄（NDCG）を正確に並べ替えるための「中程度のボトルネック」を探索する。

###### ② ターゲット: TAC risk (`tac_max_neg_path`)
* **特性:** 短期（5日先）の最大下落パス予測。暴落の予兆（VIXと金利の複合条件など）は非線形な条件分岐を伴うため、少し深い木が必要。
* **探索範囲:**
    * `num_leaves`: [7, 15, 31]
    * `max_depth`: [3, 4, 5]
    * `min_child_samples`: [100, 200, 500]
* **理由・妥当性:** riskモデルは「最悪の事態」を検知するために一定の複雑さ（条件分岐）を要するため、探索範囲をTAC alphaよりも一段階深く、太く設定する。

###### ③ ターゲット: STR alpha (`str_sharpe_adj`)
* **特性:** 中長期（60日先）のトレンド予測。ノイズが極めて多く、目先の値動きに過剰適合しやすい。
* **探索範囲:**
    * `num_leaves`: [3, 7, 15]
    * `max_depth`: [2, 3, 4]
    * `min_child_samples`: [2000, 4000, 8000]
* **理由・妥当性:** 長期予測において、少数のデータで分岐を作ることは致命傷になる。数千単位の「巨大なデータ塊」がないと分岐を許さない超保守的な空間を中心に探索する。

###### ④ ターゲット: STR risk (`str_mdd`)
* **特性:** 中長期（60日先）の致命的暴落予測。金融MLにおいて最もS/N比が低い究極の難易度。
* **探索範囲:**
    * `num_leaves`: [2, 3, 5]
    * `max_depth`: [1, 2]
    * `min_child_samples`: [4000, 8000, 12000]
* **理由・妥当性:** ノイズへの過剰適合を物理的に不可能にするため、探索範囲はStump（切り株）周辺と、極大のサンプル制約に限定する。

##### B. TCN (Temporal Convolutional Network)
時系列の局所的・大局的な依存関係を捉える1D-CNN。ターゲットの性質に合わせて、**「受容野（Window Size）」**と情報を圧縮する**「チャネル数（num_channel）」**のバランスを最適化する。

###### ① TAC alpha (`tac_vol_scaled_asym_return`)
* **特性:** 5日先の急騰予測。モメンタムやボラティリティクラスタリングといった「複雑な波」を捉える必要がある。
* **探索範囲:**
    * `num_channel`: [8, 16, 32] (複数要因の波を表現するための適度な太さ)
    * `n_layers`: [3, 4]
    * `kernel_size`: [3, 5]
    * `window_size`: [20, 40, 60] (約1〜3ヶ月のコンテキスト)
* **理由・妥当性:** 短期の右側テールを捉えるためには、直近数ヶ月のトレンドとボラティリティの文脈（コンテキスト）が必要です。ある程度の表現力（チャネル数16前後）を持たせ、時系列の連続的なパターンを学習させます。
* **固定パラメータ**
    * `dropout`: `0.15` (微細な急騰シグナルを破壊しないよう、マイルドに設定)
    * `batch_size`: `512`
    * `grad_accum_steps`: `1`
    * `loss`: `asymmetric_mse` (alpha=3.25, beta=1.0)

###### ② ターゲット: TAC risk (`tac_max_neg_path`)
* **特性:** 5日間の最大下落パス予測。突発的なパニックやショックに対する「鋭敏な反応」と、平時のノイズに対する「極度の鈍感さ」の同居が必要。
* **探索範囲:**
    * `num_channel`: [4, 8, 16] (ノイズ暗記を防ぐ強烈なボトルネック)
    * `n_layers`: [2, 3] (深すぎると過去のノイズを引きずるため浅めに)
    * `kernel_size`: [3, 5]
    * `window_size`: [10, 20, 40] (直近の異常を素早く検知するための短めの受容野)
* **理由・妥当性:** 暴落は直近の価格の急激な歪みから発生します。受容野（Window）が広すぎると、過去の平穏なデータで直近の異常シグナルが薄まってしまいます。また、複雑なモデルは「偽の暴落シグナル」を量産するため、極限まで細いチャネルと短いWindowを中心に探索します。
* **固定パラメータ**
    * `dropout`: `0.25` (偽陽性（誤報）を抑えるため、正則化を強化)
    * `batch_size`: `512`
    * `grad_accum_steps`: `1`
    * `loss`: `quantile` (quantile_alpha=0.10)

###### ③ ターゲット: STR alpha (`str_sharpe_adj`)
* **特性:** 60日先のトレンド予測。目先のノイズに惑わされず、四半期〜半年単位のマクロな要因（ファンダメンタルズの改善等）の連動を見る必要がある。
* **探索範囲:**
    * `num_channel`: [8, 16]
    * `n_layers`: [3, 4, 5]
    * `kernel_size`: [5, 7]
    * `window_size`: [60, 120] (約3ヶ月〜1年の超広域コンテキスト)
* **理由・妥当性:** 60日先を予測するモデルにとって、過去10日間の値動きは完全なノイズです。Windowを過去半年に広げ、マクロ指標や決算サイクルの大局的な連動を捉えるアーキテクチャを探索します。
* **固定パラメータ**
    * `dropout`: `0.25` (中長期トレンド予測における短期ノイズを遮断)
    * `batch_size`: `256`
    * `grad_accum_steps`: `2` (実効バッチサイズ512を確保しつつ、Window長によるメモリ負荷を抑制)
    * `loss`: `fair` (fair_c=12.0)

###### ④ ターゲット: STR risk (`str_mdd`)
* **特性:** 60日間の致命的ドローダウン予測。金融MLにおいて最もS/N比が低いタスク。特定のレジーム崩壊のみを抽出する。
* **探索範囲:**
    * `num_channel`: [2, 4, 8] (究極の情報圧縮)
    * `n_layers`: [3, 4]
    * `kernel_size`: [5, 7]
    * `window_size`: [60, 120]
* **理由・妥当性:** 「リーマンショック級の崩壊」の予兆を捉えるため、モデルの表現力を実質的に「線形回帰の少し先」レベル（チャネル2〜4）まで削ぎ落とします。1年という長いWindowの情報を、極細のチャネルに無理やり通すことで、どんな相場でも変わらない普遍的な暴落ロジックのみを抽出します。
* **固定パラメータ**
    * `dropout`: `0.35` (最も低S/Nなタスク。強烈なボトルネックにより普遍的リスクを抽出)
    * `batch_size`: `256`
    * `grad_accum_steps`: `2`
    * `loss`: `tweedie` (variance_power=1.5)

###### モデル構造に関する共通固定値
TCNの数理的整合性と、日本株クロスセクションデータにおける統計的安定性を担保するための設定。

* **`causal`**: `true` (必須。未来情報の混入（Lookahead Bias）を物理的に遮断)
* **`use_residual`**: `true` (勾配消失を防ぎ、層を深くした際の学習安定性を確保)
* **`dilation_base`**: `2` (標準的な指数受容野の拡大を採用)
* **`activation`**: `gelu` (勾配の滑らかさを優先)
* **`normalization`**: `group_norm` (推奨: `norm_groups=1`)
    * *根拠*: 日本株データはレジーム変動が激しく、BatchNormではバッチ統計量が不安定化するため、インスタンス/チャネル単位で正規化するGroupNorm（またはLayerNorm）が適している。
* **`readout`**: `last` (window末尾の隠れ状態のみを使用。Step2の基本)
* **`use_weight_norm`**: `false` (Step2では構造比較を優先し、正則化はdropoutとweight decayに集約)
* **`channel_mode`**: `constant` (チャネル数を全層で一定とし、ボトルネックの所在を明確化)
* **`optimizer`**: `adamw` (重み減衰を正しく分離して処理)
* **`learning_rate`**: `1.0e-4` (MPS環境でのLoss爆発を防ぎ、慎重にプラトーへ到達させる)
* **`weight_decay`**: `1.0e-4` (過学習抑制のベースライン)
* **`gradient_clip_norm`**: `1.0` (必須。特に非対称Lossでの急峻な勾配による学習崩壊を防止)
* **`max_epochs`**: `150`
* **`patience`**: `20 〜 30` (遅延Early Stopping。クロスセクショナル評価の振動を許容)
* **`amp` (自動混合精度)**: `false` (MPS環境かつカスタムLoss使用時の数値的不安定性を回避)
* **`num_workers`**: `0` (MPS環境でのセマフォリークやバスエラーを回避する安全策)


##### C. FT-Transformer (FTT)
テーブルデータの特徴量間相互作用（Feature Interaction）をAttention機構で動的に計算する。金融特有のノイズの多さに対応するため、**「埋め込み次元（d_token）」**と**「ブロック数（深さ）」**を厳格に制限する。

###### ① TAC alpha (`tac_vol_scaled_asym_return`)
* **特性:** 特徴量（テクニカル指標とファンダメンタルズなど）の複雑な掛け合わせが短期アルファを生む。
* **探索範囲:**
    * `d_token`: [16, 32, 64] (特徴量のニュアンスを保持する次元)
    * `n_blocks`: [2, 3] (複雑な交差を許容)
    * `attention_dropout`: [0.2, 0.3]
* **理由・妥当性:** 短期のリターン予測においては、「このモメンタムの時に、このボラティリティだと上がる」という特徴量同士のシナジーが重要です。Attentionが十分に機能するよう、ある程度の次元と深さを与えます。
* **`asym_alpha`**: 3.25 (Asymmetric MSEのペナルティ係数。最低限の非対称性を確保)
* **`ffn_dropout`**: 0.2
* **`residual_dropout`**: 0.2
* **`head_dropout`**: 0.2
*(理由: 特大急騰のトリガーとなる微細な特徴量の掛け合わせを破壊しすぎない、マイルドな正則化)*

###### ② ターゲット: TAC risk (`tac_max_neg_path`)
* **特性:** 暴落は少数の致命的特徴量（例: ボラティリティの異常値のみ）に引っ張られることが多い。Attentionの過剰な分散を防ぐ必要がある。
* **探索範囲:**
    * `d_token`: [8, 16, 32] (次元を落としてノイズを潰す)
    * `n_blocks`: [1, 2] (浅くする)
    * `attention_dropout`: [0.3, 0.4] (ノイズ暗記を防ぐため高め)
* **理由・妥当性:** riskのモデルで複雑なAttentionを構築すると、「無関係な特徴量がたまたま重なっただけのケース」を暴落と誤認します。ブロック数を浅くし、Attention Dropoutを高めることで、少数の強力なシグナルに直接フォーカスする構造を探索します。
* **`quantile_alpha`**: 0.10 (Quantile Lossの分位点。下位10%の最悪シナリオにフォーカス)
* **`ffn_dropout`**: 0.3
* **`residual_dropout`**: 0.3
* **`head_dropout`**: 0.3
*(理由: 偽陽性を防ぐためネットワーク経路を30%遮断し、極めて強いアラートのみを通過させる)*

###### ③ ターゲット: STR alpha (`str_sharpe_adj`)
* **特性:** 60日先予測。ノイズが多いため、複雑なAttentionは幻の相関（スプリアス相関）を学習してしまう。
* **探索範囲:**
    * `d_token`: [8, 16, 24]
    * `n_blocks`: [1, 2]
    * `attention_dropout`: [0.3, 0.4, 0.5]
* **理由・妥当性:** 長期予測では、特徴量の相互作用よりも、マクロ要因の単独の強さが勝ることが多いです。FTTの表現力をTAC alphaよりも大幅に削ぎ落とし、過学習を防ぎます。
* **`fair_c`**: 12.0 (Fair Lossの閾値。特大ノイズの混入を防ぎ正常なトレンドをL2学習させる)
* **`ffn_dropout`**: 0.3
* **`residual_dropout`**: 0.3
* **`head_dropout`**: 0.3
*(理由: 60日間のトレンドにおける、特定テクニカル指標の目先の変動に対する過剰適合を物理的に防止)*

###### ④ ターゲット: STR risk (`str_mdd`)
* **特性:** 究極の低S/N比環境. Attention機構すらも過学習の温床になり得るため、極限のシンプルさが要求される。
* **探索範囲:**
    * `d_token`: [4, 8, 16] (実質的に数個の特徴量しか表現できない次元)
    * `n_blocks`: [1] (相互作用は1回のみ)
    * `ffn_multiplier`: [1, 2] (ここだけ特別に動かす、過学習耐性の確認)
    * `attention_dropout`: [0.4, 0.5, 0.6] (Attentionの半分を無効化)
* **理由・妥当性:** STR riskにおいてFTTを使用する場合、その強力な表現力は「猛毒」となります。1ブロックのみに制限し、Dropoutを0.5以上の極端な値に設定することで、毎回異なる（ランダム化された）Attentionの視点から普遍的なマクロリスクだけを見つけ出させる、一種のアンサンブル的な正則化効果を探索します。
* **`variance_power`**: 1.5 (Tweedie Loss。ポアソン分布とガンマ分布の正確な中間に固定)
* **`ffn_dropout`**: 0.4
* **`residual_dropout`**: 0.4
* **`head_dropout`**: 0.4
*(理由: 最もS/N比が低いタスクのため、ネットワークの約半分を遮断する過酷な環境を作り、普遍的なマクロ構造崩壊のみを抽出する)*

###### 全ターゲット共通の固定パラメータ
* **`optimizer`**: AdamW (L2正則化と勾配スケール調整を正しく分離するため)
* **`learning_rate` (lr)**: 1e-4 (巨大バッチサイズでも局所解を飛び越えない保守的な値)
* **`activation`**: ReGLU (テーブルデータにおいて最も優れた表現力と安定性を持つため)
* **`patience`**: 20 〜 30 (遅延Early Stoppingの思想。クロスセクショナル評価での激しい振動による早期打ち切りを防止)
* **`attention_n_heads`**: 2 (極小の`d_token`空間が過度に細分化され、Attentionが崩壊するのを防ぐため)
* **`ffn_multiplier`**: 2 (FT-TransformerのFFN部分に最低限の非線形表現力を持たせつつ、金融時系列の低S/N環境で過剰な特徴量相互作用を覚えさせないため)
* **`weight_decay`**: 1e-4 (Step2の段階で重みの過剰な発散を防ぐための、ベースラインとなる収縮バイアス)

##### コスト関数パラメータの同時最適化について
本プロジェクトでは、コスト関数の形状パラメータ（`asym_alpha`等）を最終HPO（Step 4）の探索対象に含める。これは以下の理由に基づく金融MLのベストプラクティスである。
* **S/N比の改善**: ノイズパージ（Step 3）後のクリーンなデータ環境でこそ、真に最適なペナルティ形状が決定できるため。
* **正則化との相互作用**: L1/L2正則化とLossパラメータのトレードオフを同時に多変量探索（TPESampler）で解決し、バイアスとバリアンスの最適な均衡点に到達するため。

## 個別モデル実装方針（ElasticNet）
### 1. ElasticNet構築の基本原則
非線形モデル（LGBM等）とは異なり、線形モデルであるElasticNetは、入力データの数理的性質（線形性、スケーリング、多重共線性）に極めて敏感である。

- **脱・共通パイプライン**: 非線形モデル用のスクリーニング（SHAP値による足切り等）を流用せず、線形モデル独自の関数空間に最適化した独立パイプラインを構築する。
- **正則化パスの活用**: L1/L2正則化が変数選択と係数縮小を同時に行うため、事前のヒューリスティックな削減を避け、アルゴリズムの数学的収束に委ねる。

---

### 2. 特徴量エンジニアリング：ターゲット駆動型スケーリング
ターゲットの予測ホライズン（短期/長期）と目的（alpha/risk）に応じ、特徴量の「視点」を以下の通り固定する。

| モデル種別 | 主要スケーリング | 戦略的意図 |
| :--- | :--- | :--- |
| **STR_alpha** | **SNZ + TSZ** | 「業種内の相対的優位」と「自身の過去からのブレイクアウト」の同時成立（ゴールデン・クアドラント）を狙う。 |
| **STR_risk** | **Z-score + RAW** | 相対評価（Z）の盲点を、絶対的アンカー（RAW：比率/対数化済）によるサーキットブレーカーで補完する。 |
| **TAC_alpha** | **CSZ / CSR** | 市場全体の「今この瞬間」の資金集中（人気投票）を最速で捉える。 |
| **TAC_risk** | **CSZ** | 市場平均からの極端な乖離（テールリスク）を、マグニチュードを保持したまま検知する。 |

#### 【重要】数理的禁忌事項（監査結果）
- **NaN爆弾の排除**: 市場共通指標（TOPIXリターン等）をクロスセクション処理（CSZ/CSR）してはならない（分散ゼロによるゼロ除算が発生するため）。
- **スケール汚染の防止**: 金額、株数、指標の絶対値（EPS、出来高、株価依存指標）をRAWで投入してはならない。必ず比率化、対数化、または標準化を行う。
- **冗長性のパージ**: 同一指標の `CSZ` と `CSR（ガウスランク）` の同時投入は、L1正則化パスを不安定化させるため禁止する。

---

### 3. モデル別・最終特徴量選定ロジック

#### 3.1 STR (中長期) モデル
- **STR_alpha**: 「空間的優位（SNZ）」と「時間的変化（TSZ）」をペアで投入し、線形和によるスコアリングを最大化する。
- **STR_risk**: 「ゆでガエル現象（市場全体の緩慢な崩壊）」を防ぐため、200日線乖離率、ATR比率、対数PBR、絶対流動性等の「絶対的レッドライン（RAW）」を重層的に配置する。

#### 3.2 TAC (短期) モデル
- **TAC_alpha**: 短期の過熱感を捉えるため、CSR（ガウスランク）による順位優位性を重視。短期のノイズ（1d/3dリターン等）を適切に制御し、5d〜10dのモメンタムを核とする。
- **TAC_risk**: パニック時の異常値を正確に捕捉するため、外れ値を丸めないCSZ（Zスコア）を優先し、スプレッド（SPD）や流動性スパイクを監視する。

---

### 4. Phase 3: ハイパーパラメータ最適化（CPCV）
M5プロセッサのマルチコア性能を活かし、Optuna（ベイズ最適化）ではなく「正則化パス（グリッド探索）」による全数探索を行う。

#### 4.1 探索空間の非対称設計
**目的関数が凸関数であるため**、ウォームスタートを効かせたパス探索が最も効率的である。

- **alphaモデル（スパース性重視）**: 
    - `l1_ratio`: [0.5, 0.7, 0.9, 0.95, 0.99, 1.0] （少数の強シグナルに絞り込む）
    - `alpha`: $10^{-5}$ 〜 $10^1$ (100点)
- **riskモデル（冗長性重視）**: 
****    - `l1_ratio`: [0.0, 0.01, 0.05, 0.1, 0.2, 0.3, 0.5] （多重防衛のため全変数を保持するRidge寄り）
    - `alpha`: $10^{-4}$ 〜 $10^3$ (100点)

#### 4.2 評価メトリクス
単一のWorst-Foldを追うのではなく、CPCVによって生成される多数の検証パス（OOS）の分布を評価する。
- **採択基準**: $\text{Mean}(SR) - 1.0 \times \text{Std}(SR)$ の最大化。
- これにより、期待収益率が高く、かつレジーム変化に強い（ボラティリティが低い）パラメータセットを特定する。
